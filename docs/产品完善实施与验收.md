# 产品完善实施与验收

日期：2026-10-23。源码与本地验证，不自动发布。

## 已交付

- 密钥库支持重新验证主密码后导出 `.dbxvault` 加密备份。保存取消不会显示成功。备份使用备份时的主密码，后续改密不改变旧文件。
- 恢复按“选择文件 → 备份密码 → 预览 → 确认追加”执行；目标必须先创建或解锁。相同条目跳过，同名不同内容保留，已有数据不覆盖。预览五分钟有效，锁定即失效，期间数据改变须重新预览。
- 恢复内容只在 Sidecar 解密，前端只收到计数和预览令牌。备份输入分块传递，上限 16 MiB；不纳入偏好、工具输入或任务记录。
- 普通工具仍以八个页面为工作集。优先释放无编辑、无任务、无未保存结果的页面；全部受保护时选择要关闭的页面，或取消打开新工具。
- 接入内容保护的工具标签显示未保存标记；关闭、替换文件、加载示例和清空通用编辑器经过保护。支持导出时可先导出；失败或取消保留工作。下列七个简单工具不接入新增的编辑保护交互。
- PDF、GIF、OCR 和模型下载在切换页面后继续执行。后台工具会话独立保留，不占普通页面的八页额度。关闭活跃会话可保留任务并隐藏，或者取消并释放。关闭工作台不提供续跑或会话恢复。
- PDF 隐藏时清除界面密码，已开始的操作使用启动快照。GIF 图片序列编码放入可终止 Worker，避免编码阻塞界面。
- 任务中心可以返回工具、保存当前结果、取消任务、显示安全的失败原因和有条件重试。清除记录不删除工具中的未保存结果；清除前会提示。
- 首页已按用户要求移除“从任务开始”区块及四组推荐卡片，保留搜索、最近使用、收藏和分类入口。首页、目录和启动器搜索支持文本／数据、图像、文档筛选；目录空结果可以清除筛选或使用示例查询。
- PDF 压缩在处理前说明结构优化边界，处理后显示体积变化；不缩小时明确提示保留原文件。表格保留只读单元格值的边界说明。加密高级参数按需展开；语音和端口工具提供环境排错路径。
- 设置提供插件版本、限制、更新说明和脱敏诊断复制。诊断只包含插件版本、系统类别、语言和桥接能力，不复制输入、密钥、路径、SQL 或连接资料。

## 已恢复的简单工具

按用户要求，JSON 工作台、数据格式转换、电子表格、文本处理、正则测试、Base 编解码和图片文字识别 OCR 恢复本轮改造前的操作方式。移除新增的跨工具发送、专用状态与导出接入，以及新增的编辑、清空和覆盖确认。这些工具原先已有的导入、导出和处理功能继续保留。

OCR 参数恢复直接展示，文本导出继续使用来源文件名。识别和模型下载已有的任务功能保留。上述工具之间继续通过用户主动复制粘贴传递结果，不增加自动工作流。

## TOTP 与统一密钥库联调（2026-10-24）

- 使用当前构建的 Rust Sidecar，在独立临时目录验证统一解锁、两个入口锁定、修改主密码后重新解锁、密钥与 TOTP 同时恢复、重复导入、篡改、错误密码、预览失效和并发写入。
- 验证改密前的备份仍使用原密码恢复，账户备注随统一存储保留，TOTP 不进入通用密钥列表。
- 自动锁定广播明确的锁定状态，TOTP 立即清除账户选择、验证码、已显示密钥及敏感草稿；状态轮询检测其他入口或工作台导致的锁定。异步旧响应不能重新填回已清除的数据。
- 页面卸载清除临时输入、已显示密钥及轮询资源。前端行为测试使用隔离事件和时钟，原生联调不读取用户密钥库；不新增 TOTP 历史迁移或兼容路径。
- 文字朗读修正滑块轨道的伪元素选择器，语速和音高按当前值更新填充比例；在浏览器开发宿主验证浅色、深色主题和方向键操作。
- 此次不等同于真实 DBX 桌面、macOS 和 Linux 全平台验收，原生文件选择及保存取消仍需对应环境验证。

每项记录开始时间、首次打开正确工具时间、完成时间、是否成功、复制粘贴次数和失败后恢复方式。仅人工记录，不增加联网统计。

| 任务 | 成功判定 | 改造前定性基线 |
| --- | --- | --- |
| 搜索“JSON 转 CSV”并转换示例 | 找到正确工具并获得 CSV | 已支持意图直达 |
| 搜索“压缩”，限定 PDF | 正确区分文本、图像、文档 | 无统一处理对象筛选 |
| 文本清理后进入正则测试 | 可手动复制结果到正则测试 | 继续使用原有复制粘贴方式 |
| 编辑受保护工具后打开第九个普通工具 | 受保护内容未被静默释放 | 按最近使用直接淘汰；七个简单工具保留原有交互 |
| PDF 处理时切到首页再返回 | 任务继续且结果可保存 | PDF 页面销毁会取消 |
| 损坏备份恢复失败后重试 | 已有条目不受损，正确备份可恢复 | 无统一备份恢复界面 |
