# 工具箱功能扩展实施说明

日期：2026-10-21。未更改插件发布版本，已生成本地未签名验收包；未对外发布。

目录共 147 条定义，141 个可见入口：117 个工具入口、24 个快捷入口，另有 6 个隐藏父级定义。本轮增加 52 个可见入口及两个电子表格导出选项。

## GIF 与语音

保留原“GIF 动画生成”。新增“GIF 压缩”“GIF 裁剪”“GIF 帧编辑”，导入已有 GIF，共享 Worker 解码、帧合成、转换和编码。最多 30 MB、300 帧、2400 万总像素，保留帧时长、循环和透明度；丢帧合并对应时长，输出增大时如实提示。帧编辑支持单帧 PNG 提取。

“文字朗读”只选择 `localService` 为真的系统语音，没有本地语音时显示不可用。

## PDF

15 个独立入口：PDF 合并、PDF 拆分、PDF 页面整理、PDF 页面旋转、PDF 删除页面、PDF 提取页面、PDF 文字水印、PDF 添加页码、PDF 页面裁剪、PDF 视觉签名、PDF 转图片、PDF 压缩、PDF 密码加密、PDF 密码解密、PDF 数字签名检查。

- 每个入口独立导入、处理、导出，共享解析、页码范围、缩略图和导出模块。所有输出为新文件。
- 合并、拆分、旋转、删除、提取、裁剪、压缩、加密和解密改由 Rust Sidecar 通过分块上传与临时文件处理：最多 20 个文件、单文件 512 MB、总计 1 GB、5000 页。需要浏览器渲染的页面整理、加水印、页码、可视签名、转图片与签名检查仍采用原限制：单文件 50 MB、总计 100 MB、500 页，输出总计不超过 100 MB。
- PDF 页面整理提供缩略图、拖拽和按钮排序。拆分和多页图片输出打包 ZIP。
- 水印和页码内置拉丁字体；其他文字可选择包含对应字形的本地 TTF/OTF 字体，字体不联网下载。
- 视觉签名支持手写及 PNG/JPEG，是图像叠加。位置使用 PDF 点、左下角原点。
- PDF 压缩移除元数据和缩略图并重写对象流，不对扫描图降采样；不保证体积减小。
- 密码加密使用 AES-256；解密需要已知密码。
- 数字签名检查验证支持的 detached CMS 内容完整性、当前文件覆盖范围、证书有效期；内部链一致性与系统信任分开显示。系统根信任、在线吊销检查、时间戳和不支持的签名格式显示未验证，不联网。

## 接入与验证

所有入口沿用现有目录、搜索、语言和 Host Bridge。较大的第三方依赖以自包含资源按需加载。敏感工具和 PDF 页面离开时销毁；不新增 Host API 或网络权限。

OCR、摄像头录制、AI 提示词、公网 IP、DNS/DoH、MAC 厂商查询均未扩展。

验证包含算法向量、格式边界、BIP39 标准种子、GIF 透明度与时序、PDF 页序、密码闭环及有效/篡改签名。真实 DBX 桌面安装与跨平台发布验收仍需在对应环境执行。
